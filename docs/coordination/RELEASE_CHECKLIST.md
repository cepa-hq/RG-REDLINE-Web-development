# Scoped release checklist

Use for each website deployment; skip inapplicable items with a reason.

- [ ] Target domain/environment verified, authorization recorded and existing authorization reused.
- [ ] Related active tasks inspected; single release owner and release window recorded.
- [ ] Current source/live state matches baseline; unexpected changes resolved cooperatively.
- [ ] Exact reviewed artifact/commit/hash and shared dependencies recorded.
- [ ] Before checkpoint and scoped rollback available; no sensitive backups uploaded here.
- [ ] Only claimed pages/files/settings will change; other agents’ work preserved.
- [ ] No whole-database replacement without a separately reviewed, authorized migration plan.
- [ ] Applicable syntax/build, functional and commerce checks passed; unrun tests disclosed.
- [ ] Desktop/phone/tablet, keyboard and reduced-motion behavior checked.
- [ ] Errors, asset sizes/loading and animation overhead reviewed.
- [ ] WooCommerce variation/cart/checkout/order/payment behavior checked when affected.
- [ ] Correct domain/canonicals, robots/noindex, sitemap, icon and metadata checked.
- [ ] Environment-specific integrations, consent, cache and email/payment behavior checked when affected.
- [ ] Live smoke checks and exact release status recorded after deployment.
- [ ] Release claim ended and task checkpoint updated; review/close criteria assessed.
